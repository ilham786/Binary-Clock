📡 How the Binary Display Works

Hours (0–23)

H₁₀: tens digit (0–2) in 2 bits
H₁: units digit (0–9) in 4 bits
e.g. 14 → tens=1 (0001) units=4 (0100)

Minutes (0–59)

M₁₀: tens digit (0–5) in 3 bits
M₁: units digit (0–9) in 4 bits
e.g. 35 → tens=3 (0011) units=5 (0101)

Seconds (0–59)

S₁₀: tens digit (0–5) in 3 bits
S₁: units digit (0–9) in 4 bits
e.g. 52 → tens=5 (0101) units=2 (0010)

Reading the Clock

Top row = bit weight 8
2nd row = bit weight 4
3rd row = bit weight 2
Bottom row = bit weight 1
Sum the ON LEDs per column.
